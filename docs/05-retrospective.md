# 复盘

## 最难的问题

把模型自主决策和业务底线分开：模型决定继续、替换或停止，程序独立计算费用、核验步骤和截止时间，防止模型把超预算方案或失败步骤报成成功。已发生的模拟脚本费用与将来素材、编辑费用分开，重估不重复收取已复用步骤。

另一个难点是恢复：SQLite 保存每次尝试和已有结果，失败后续跑由模型重新选择动作，原本成功的检索与脚本可以复用。真实生产系统还需要处理并发、进程意外中断时的外部副作用和供应商幂等，本次未覆盖。

## 实际投入和学习

本次 Codex 实施于 2026-11-11 北京时间约 16:37 开始，约 17:04 完成，历时约 26 分钟（含用户配置密钥及联调时间）。用户个人学习或其他修改耗时未提供，不能推定。

Windows 沙箱不允许测试直接使用默认临时目录中的 Python 私有目录；最终改用项目内隔离文件并完成测试。首次真实模型请求也受到沙箱网络限制，获准联网后完成了三条真实调用。模型曾一次发起多个动作，程序返回逐个执行的要求；随后补全了被拒绝动作的 Trace 并复测。

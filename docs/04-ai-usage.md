# AI 使用说明

本项目根据用户提供的题目、考核规则和确认的方案，由 Codex 辅助设计并编写代码、测试、示例和文档。Codex 运行了离线示例与自动化测试，测试记录见 [test-results.txt](../examples/test-results.txt)。

用户提供了题目、验收和交付要求，确认选择完整本地项目及兼容模型接口，先指定 `deepseek-v4-flash`，随后要求使用 `.env` 配置并将模型名设为 `deepseek-flash`，并自行在本地填写接口密钥。用户的后续代码修改、验证及答辩准备应按实际情况补充。

Codex 已使用用户配置的接口运行三条真实模型路径，记录见[评估](03-evaluation.md)。业务素材和脚本仍为合成示例，内容事实和品牌适配需要另行验证；不得将离线 Mock 或模拟 HTTP 响应写成真实模型实测结果。
